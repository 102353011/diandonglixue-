📝 解题解析 (数学证明)

1. 伽利略变换
设 S 系静止，S' 系以速度 v 沿 x 轴运动。
坐标变换：
x' = x - vt
y' = y, z' = z
t' = t (绝对时间)
2. 牛顿定律协变性证明
对坐标求导得速度变换：
u' = dx'/dt = u - v
再对时间求导得加速度变换：
a' = du'/dt = du/dt = a
(因为 v 是常数，dv/dt = 0)
在经典力学中，质量 m 和力 F 是伽利略不变量：
m' = m, F' = F
因此，在 S' 系中：
F' = m'a' = ma = F
结论：F = ma 形式不变，牛顿定律协变。
3. 麦克斯韦方程不协变性证明
麦克斯韦方程导出电磁波速度：
c = 1 / √(ε₀μ₀) (常数)
根据伽利略速度叠加原理：
若光沿 x 轴正向传播，S 系中光速为 c。
在 S' 系中观察，光速应为：
c' = c - v
显然 c' ≠ c，光速不再是常数。
这意味着麦克斯韦方程组在 S' 系中形式发生改变（包含光速的项不再匹配）。
结论：麦克斯韦方程在伽利略变换下不协变。
